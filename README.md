# Hotel Management
Group project for Database Design and Implementation. Hotel Management software should include a customer, reservation, and search menu with CRUM features.
Should be able to connect to a database and include log-in and exit options.

# Connecting to Database
Using Intellij:
- To get database file location, right click DB file in the project explorer
- Select "Copy Path/Reference" and select "Absolute Path"
- Replace after "jdbc:ucanaccess://" in the URL
- private static final String DATABASEURL = "jdbc:ucanaccess://C:\\Users\\James\\IdeaProjects\\
    Hotel-Management\\src\\main\\java\\com\\example\\hotelmanagement\\database\\HotelManagementSoftwareDatabase.accdb";

  # Running software
  To test using console, run Main.java.
  To run actual software with JavaFX, run HotelManagement.java file.
